# 원자료 안내

이 폴더는 원자료 보관 위치를 설명하기 위한 자리이다.

예상 원자료:
- SGIS 집계구 인구·가구·종사자·사업체·업종 데이터
- VWorld 토지이용계획/용도지역 데이터
- 건축물대장 또는 건축HUB 기반 건축물 데이터
- LMS 제공 subway_network.zip 내부 `nodes.tsv`, `links.tsv`
- 필요 시 버스정류장, 도로망, 역세권 분석용 보조 데이터

현재 제출본에는 원자료가 포함되어 있지 않다. 실제 분석 재현 시에는 저작권·이용약관을 확인한 뒤 이 폴더 하위에 저장하고, `scripts` 폴더의 명령으로 `data/processed`와 `public/data/processed`를 다시 생성해야 한다.
