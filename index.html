핵심 지표 카드

총인구, 고용 집적, 경계 면적, 등시간권 접근성을 한 화면에서 비교한다.

실제 수치 비교표

총인구는 해석 주의가 필요하며, 총종사자수·총사업체수·직주비는 업무지구 활성화 핵심 지표로 본다.
지표 판교 청라 차이/배율 우세 지역 해석

비교 그래프

정규화 지수 = 해당 지역 값 / 두 지역 중 더 큰 값 × 100. 단위가 다른 지표를 함께 비교하기 위해 정규화했다.

업무지구 활성화 핵심 지표 비교

주석: 총종사자수, 총사업체수, 직주비를 함께 보면 판교가 청라보다 실제 업무·고용 집적이 훨씬 강한 구역이라는 점이 분명하게 드러난다.

인구·고용 구조 비교

주석: 청라는 상주인구가 더 크지만 고용과 사업체 집적은 판교가 우세하므로, 인구 규모만으로 업무지구의 성공 여부를 판단하기 어렵다.

등시간권 변화에 따른 도달 노드 수

주석: 시간 증가에 따라 두 지역 모두 도달 범위가 넓어지지만, 판교는 핵심역을 중심으로 더 많은 철도 노드에 연결되어 광역 네트워크 접근성이 상대적으로 강하게 나타난다.

교통 접근성 보조지표 비교

주석: 버스정류장과 도로, 철도 접근성 보조지표를 함께 보면 판교가 청라보다 업무지구 운영에 필요한 복합 교통 기반이 더 촘촘한 편으로 읽힌다.

용도지역 구성 비교

주석: 용도지역 구성 차이는 두 지역의 계획 성격 차이를 보여주며, 판교는 실제 업무기능과 결합된 토지이용 구조를, 청라는 상대적으로 다른 성격의 공간 구성을 시사한다.

도시 형태 지표 비교

주석: LUM, 건축 footprint 비율, 건축물 수를 종합하면 판교가 청라보다 실제 개발 집적과 업무지구 형태의 밀도가 더 높은 구역으로 해석된다.

비교 해석

실제 확보한 수치와 현재 polygon 기준 재계산 결과만 사용한다.

건축물 건축물대장 기본개요 / 건축물 공간자료 국토교통부 건축HUB / 전처리된 건축물 GeoJSON 확보 자료 기준 건축물 / 대지 단위 건축물 클릭 속성, 주용도, 건축물 수, footprint 기반 면적 확인 실제 반영 원본 건축HUB 기본개요 CSV는 확인되지만 연면적·용적률 원필드는 현재 정적 제출본에 직접 포함하지 않았다. 따라서 클릭 패널에는 실제 주용도와 공간자료 기반 면적, 필요 시 추정 연면적만 표시하고 실제 용적률은 미확보로 둔다. 원자료 예시: `pangyo_building_basic_2023.csv`, `cheongna_building_basic_2023.csv`

지도 배경 OpenStreetMap Tile OpenStreetMap contributors 타일 제공 시점 지도 타일 Leaflet 배경지도 실제 반영 분석 지표 산출에는 직접 사용하지 않고 위치 확인과 시각화를 위한 배경지도로만 사용한다.
시각화 라이브러리 Leaflet, Chart.js, Turf.js 각 오픈소스 라이브러리 공식 CDN 접속 시점 해당 없음 Leaflet은 지도 시각화, Chart.js는 그래프 작성, Turf.js는 polygon 면적 계산 실제 반영 라이브러리는 분석 원자료가 아니라 시각화 및 계산 도구다.
본 시스템은 확보된 자료만 실제값으로 표시하며, 자료가 없거나 새 boundary polygon과 정합성이 확인되지 않은 항목은 데이터 미확보로 처리하였다. 따라서 그래프와 해석은 실제 반영된 지표를 중심으로 작성하였다.
