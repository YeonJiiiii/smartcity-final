# AI 활용 내역

## 사용 목적

- 정적 웹 인터페이스 구조 설계
- 데이터 스키마 설계
- 전처리 스크립트 골격 작성
- README, 방법론 문서, 보고서 초안 작성 지원

## 검증 원칙

- AI가 생성한 수치·출처·사실은 원자료 또는 사용자 제공 검증값으로 확인된 경우에만 시스템에 반영한다.
- 이번 제출본에서는 사용자 제공으로 확정된 핵심 5개 지표만 숫자로 반영하였다.
- 토지이용, 건축물, 철도 네트워크 관련 수치는 원자료가 확보되지 않아 생성하지 않았다.

## 한계

- AI는 실제 원자료를 대체하지 않는다.
- 원자료 미확보 상태에서는 구조, 문서, 코드 골격만 제공할 수 있다.
- 최종 제출 전 사용자는 원자료 재검증과 수치 확정을 수행해야 한다.
